# 01. 현재 사이트 진단 (2026-11-15)

방법: 서버 모드 화면을 Playwright(Chromium)로 1440px·390px 폭에서 10개 화면 전체 캡처하고 코드를 읽었다.

| 구분 | 진단 (개편 전) | 분류 | 우선순위 |
|---|---|---|---|
| 메인 히어로 | 마스코트 그림만 있고 동해 사진이 없어 '어디 여행인지'가 첫 화면에서 안 보임 | REDESIGN | P0 |
| 메인 정보 구조 | 히어로 → 코스 만들기 → 예시 코스 3개로 끝. 관광지·교통·지도·행사로 가는 길이 상단 메뉴와 바닥글뿐 | ADD | P0 |
| 확인 범위 | 몇 곳을 확인했는지 숫자가 화면에 없음 (데이터는 서버에 있음) | ADD | P0 |
| 관광지 목록 | 사진이 있는 장소는 8곳, 나머지는 그림. 사진이 안 불러와지면 깨진 이미지 아이콘이 보임 | IMPROVE | P0 |
| 예시 코스 카드 | 글자만 있음 | IMPROVE | P1 |
| 코스 만들기 | 대화·달력·지도·시간표 정상 동작. 왼쪽 패널이 화면 높이에서 잘려 안쪽 스크롤이 생김 | KEEP / IMPROVE | P1 |
| 장소 상세·교통·지도·행사·숙소·준비·출처 | 기능 정상. 화면 머리 부분이 글자 위주로 단조로움 | IMPROVE | P1 |
| 내 일정 | 브라우저 저장만 지원 (로그인 없음) | KEEP | P2 |
| 검색 | 장소 이름 검색창 없음 (대화 입력으로만 가능) | ADD | P1 |
| 모바일 | 가로 넘침 없음. 하단 탭바 정상 | KEEP | - |
| 사진 파일 | 저장소에 사진 파일이 없고 위키미디어 공용 주소를 직접 불러옴 | IMPROVE | P1 |
