## 2026-11-17 — 코스 짜기 한 화면에 · 담기 알림 · 전체 탭 · 이렇게 써요
사용자로 처음부터 써 보며 찾은 문제와 고친 내용.
- 코스 짜기 대화 칸을 위(진행 단계 6칸)·가운데(대화, 이 칸만 스크롤)·아래(답 버튼과 입력칸)로 나눔. 입력칸은 어느 단계에서든 늘 보임. 머리말·아래 탭 높이를 재서 화면 높이에 꼭 맞춤 (1280×720, iPhone 13, iPhone SE에서 '다음'과 입력칸이 한 화면 안에 들어오는 것 확인)
- 날짜 고르기: 큰 달력 대신 앞으로 2주를 한 줄로, 더 먼 날은 '달력'을 펼쳐 고름. '다음' 버튼에 고른 날짜·시각을 함께 표시
- 코스 만들기 전 오른쪽에 '내 여행 조건' 카드: 고른 조건과 꼭 갈 곳이 채워지는 모습이 보임 (빼기 가능)
- 코스에 담기: 누르면 아래 알림이 뜨고(코스가 있으면 '지금 코스에 넣기'), 다시 누르면 빠짐. 다른 화면에서는 '담은 곳 n곳 · 코스 만들기' 버튼이 떠 있음. 장소 상세에서도 같은 동작
- 관광지 권역 탭 맨 앞에 '전체'(기본값), 전체 보기에서는 카드에 권역 이름 표시
- 홈에 '이렇게 써요' 3단계 안내 (조건 고르기 → 갈 수 있는 코스 받기 → 고치고 저장·공유)
- 작은 폰에서 머리말을 한 줄로 (400px 이하는 로고 글자 숨김)
- 연필뮤지엄 사진 2장 추가 (팀 제공)
