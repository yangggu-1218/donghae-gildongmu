# 07. 디자인 시스템 (frontend/app/globals.css 의 토큰이 기준 · 자세한 기준은 저장소 맨 위 DESIGN.md)

방향: Public Service(신뢰·큰 글씨) + Map-first(지도와 시간표를 나란히) + 실제 사진. 마스코트 동이의 파랑·주황을 그대로 쓴다.

- 색: 바다 `#2462B4`, 깊은 바다 `#12355E`, 해 `#F29A33`, 바탕 `#F3F8FD`, 글자 `#14243A`. 판정색은 초록 `#1E7F38` / 노랑 `#7A5300` / 빨강 `#C2302C` 이며 색만으로 구분하지 않고 항상 글자를 같이 쓴다.
- 글꼴: 제목 Jua, 본문 IBM Plex Sans KR. 본문 16px, 줄간격 1.65. '글자 크게 보기'로 전체 확대.
- 모서리: 28 / 18 / 12px. 버튼·입력 최소 높이 44px (히어로 입력 52px).
- 사진: 사진 위 글자는 항상 남색 그라데이션(불투명도 0.66 이상) 위에 흰 글자. 사진을 못 불러오면 권역색 바탕이나 그림이 대신 보인다. 출처는 사진 위가 아니라 '출처·판정 기준' 페이지에 모은다.
- 컴포넌트: 히어로(.hero), 숫자 띠(.facts), 권역 타일(.ztile), 예시 코스 카드(.ccard), 링크 카드(.more-grid), 패널(.panel), 칩(.chip), 판정 배지(.badge g-G/Y/R).
- 움직임: 권역 타일 사진 확대만. prefers-reduced-motion 이면 끈다.
