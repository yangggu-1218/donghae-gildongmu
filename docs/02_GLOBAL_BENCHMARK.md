# 02. 레퍼런스 조사 (2026-11-15, 실제 접속한 것만 기록)

| 사이트 | URL | 본 화면 | 참고한 점 | 우리 적용 | 가져오지 않은 것 |
|---|---|---|---|---|---|
| 대한민국 구석구석 | https://korean.visitkorea.or.kr/main/main.do | 메인 | 상단 메뉴를 여행·추천·테마·지역으로 단순하게 나눔, 큰 대표 이미지 | 메인에 '권역으로 둘러보기' 사진 타일 | 자동으로 넘어가는 배너 (고령 사용자가 읽기 전에 넘어감) |
| Wanderlog | https://wanderlog.com/ | 메인 | 한 문장 제목 + 행동 버튼 하나, 바로 아래에 일정과 지도가 나란한 실제 화면 | 히어로에 입력창 하나만 두고 바로 아래에 대화·지도 2단 | 가입 유도 |

접속했지만 확인하지 못한 곳
- AllTrails (https://www.alltrails.com/): 기기 확인(봇 차단) 화면에서 멈춰 내용을 보지 못했다.
- 열린관광 모두의 여행 (access.visitkorea.or.kr/main.do): '페이지를 찾을 수 없음'이 나왔다. 주소 확인 필요.

아직 조사하지 않은 곳: 지시서의 나머지 레퍼런스(Airbnb, Tripadvisor, Klook, 토스, 공공기관 등)는 이번 단계에서 접속하지 않았다. 다음 단계에서 페이지별 개편 전에 해당 화면만 골라 조사한다.
