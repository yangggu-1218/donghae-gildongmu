# 공공데이터(파일데이터) 넣는 법

1. 공공데이터포털에서 받은 CSV를 `data/public/raw/` 에 넣는다 (파일 이름, UTF-8/CP949 상관없음).
2. `python scripts/ingest_public.py` → `public_data.json`, `report.md` 생성. 서버를 다시 켜면 반영된다.
3. `report.md` 의 '확인이 필요한 값'과 '아직 모르는 데이터'를 본다. 모르는 데이터는 `scripts/ingest_public.py` 의 SCHEMAS·FIELDS에 추가.
4. 길동무 장소와 공공데이터 이름 연결은 `place_links.csv` 에서 고친다.
